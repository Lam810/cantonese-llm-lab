# 評測數字

模型：某粵語 LoRA 微調（Qwen3-0.6B 基座，r=8，target = q_proj/v_proj）vs 原始 Qwen3-0.6B。

## HKMMLU（n = 3300，66 個 config 各取 50 題，標準誤約 0.8pp）

**以下是關閉思維鏈的數字**（`enable_thinking=False`）。為什麼必須關：選擇題是比較第一個位置上
A/B/C/D 的 logprob，而 Qwen3 默認開思維鏈、第一個 token 是 `<think>`，量到的是
「它想先想一想」而不是它的知識。見 [`v2_results.md`](v2_results.md) 的說明。

| | 總體 | HK 子集 | HKDSE 子集 |
|---|---|---|---|
| 微調模型 | **30.27%** | 36.78% | 26.67% |
| 原始基座 | **29.85%** | 35.04% | 26.00% |
| 隨機基線 | 25.00% | 25.00% | 25.00% |

**兩者差距 0.42pp，在誤差內 = 等於零。** 只喂問答數據的 LoRA 不會帶來知識增益，這是預期之內的。

作為對照，同一套題**開著思維鏈**測出來是 31.48% / 31.06%（HK 子集 39.39% / 38.17%）。
兩種設置下結論都是「差距等於零」，但**絕對值不可混用**——
在 8B 那一對上，同樣的混淆把基座從真實的 57.00% 壓到了 28.88%（近隨機）。

## 生成質量（30 條粵語提問，貪心解碼，max_new_tokens=128，**思維鏈開啟**）

| | 退化率 | 書面粵語純度 | 中位回答長度 |
|---|---|---|---|
| 微調模型 | **93.3%** | 0.890 ⚠️ | 129 |
| 原始基座 | **0.0%** | 0.013 | 224 |

⚠️ **純度這一欄單看會騙人。** 0.890 是在退化文本上算出來的——第一條回答整串「咢」裡
只要出現一個「嘅」，`yue/(yue+zh)` 就是 1.0。基座的 0.013 則是另一個事實：
原始 Qwen3-0.6B **基本不寫粵語**，它用普通話回答粵語提問（實測 yue=0 / zh=28）。

所以誠實的讀法是：這次 LoRA **確實把語域從普通話推向了粵語**（0.013 → 0.890 不是噪聲），
但同時把生成能力毀掉了。兩個指標必須綁在一起看。
